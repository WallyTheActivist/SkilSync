**Data policy:** All people, accounts, organizations, and records below are synthetic. Use `@skillsync.test` accounts and a dedicated test database only. No production credentials or personal data belong in test evidence.

**Status values:** `PASS` or `FAIL` only after execution; `PENDING / NOT EXECUTED` before execution; `BLOCKED` when a required environment is unavailable. Expected results are not actual results.
